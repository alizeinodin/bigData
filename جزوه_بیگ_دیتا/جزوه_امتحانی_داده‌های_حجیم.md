# جزوه امتحانی داده‌های حجیم

نسخهٔ اصلی و خوانا برای چاپ/امتحان این فایل‌هاست:

1. **`جزوه_امتحانی_داده‌های_حجیم.pdf`** — جزوه کامل (چیت‌شیت + راهنمای صفحات اول جزوه + همه بخش‌ها + حل نمونه سوالات)
2. **`چیت_شیت.pdf`** — چیت‌شیت یک‌صفحه‌ای جدا برای چاپ سریع
3. **`جزوه_امتحانی_داده‌های_حجیم.html`** / **`چیت_شیت.html`** — نسخه مرورگر

## ترتیب محتوا در PDF اصلی
1. چیت‌شیت سریع (تعاریف + فرمول‌ها)
2. راهنمای صفحات / ایندکس
3. §۱ تا §۹ مباحث
4. §۱۰ حل نمونه سوالات استاد

> فرمول‌ها داخل باکس‌های سبز و با فونت monospace چپ‌به‌راست نوشته شده‌اند تا در چاپ فارسی خوانا بمانند.
