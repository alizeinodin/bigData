# چیت‌شیت یک‌نگاهی — داده‌های حجیم

پاسخ امتحان = تعریف یک‌خطی + فرمول + مثال کوتاه

## تعاریف
- Shingle: دنباله k توکن متوالی
- Jaccard: |A ∩ B| / |A ∪ B|
- MinHash: Pr[h برابر] = Jaccard
- LSH: فقط candidateهای مشابه
- Collaborative Filtering: توصیه با کاربران/آیتم‌های مشابه
- Closed: بدون ابرمجموعه با همان support
- Maximal: بدون ابرمجموعه frequent
- MapReduce: Map + Reduce + fault tolerance

## فرمول‌ها

TF-IDF:
```
TF = f / max_f
IDF = log2(N / n)
TF-IDF = TF × IDF
مثال: N=1024,n=128,f=10,max=100 → 0.1 × 3 = 0.3
```

Jaccard / MinHash / LSH:
```
J = |A ∩ B| / |A ∪ B|
Pr[hπ(C1)=hπ(C2)] = J
P = 1 − (1 − s^r)^b
thr ≈ (1/b)^(1/r)
```

فاصله‌ها:
```
L2: sqrt(Σ(xi−yi)^2)
L1: Σ|xi−yi|
Lr: (Σ|xi−yi|^r)^(1/r)
L∞: max|xi−yi|
Cos: (x·y)/(||x||||y||)
Ham: # diffs
Edit: |X|+|Y|−2|LCS|
Nom: (p−m)/p
Bin: (r+s)/(q+r+s)
```

MapReduce ماتریس×بردار:
```
Map:  (i, m_ij × v_j)
Reduce: u_i = Σ values
مثال: M=[[1,0,5],[7,3,0],[1,3,5]] V=[2,4,6] → U=[32,26,44]
```

Association / Closed:
```
sup(A⇒B)=sup(A∪B)
conf=sup(A∪B)/sup(A)
M ⊆ C ⊆ F
```

Cluster vs RDBMS:
```
RDBMS: vertical, ACID, expensive
Cluster: horizontal, commodity, replication, code→data
```

Clustering:
```
goal: min intra / max inter
K-Means: centroid + SSE
K-Medoids: real point
DBSCAN: Core/Border/Noise
BFR: N,SUM,SUMSQ
```
