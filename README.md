# جزوه امتحانی داده‌های حجیم

این مخزن شامل جزوه فشرده امتحانی درس **تحلیل‌ها و سیستم‌های داده‌های حجیم** (دکتر فرساد زمانی بروجنی) است که از لکچرهای ترم استخراج شده.

## فایل‌های اصلی

| فایل | توضیح |
|---|---|
| `جزوه_بیگ_دیتا/جزوه_امتحانی_داده‌های_حجیم.pdf` | **نسخه چاپی/امتحانی (پیشنهادی)** |
| `جزوه_بیگ_دیتا/جزوه_امتحانی_داده‌های_حجیم.html` | نسخه مرورگر |

| `extracted/` | متن خام استخراج‌شده از PDFهای لکچر |

## ساختار جزوه

1. مقدمه Big Data و TF-IDF  
2. Cluster Computing ↔ RDBMS  
3. MapReduce + جبر رابطه‌ای + ضرب ماتریس  
4. Shingle / MinHash / LSH / Jaccard  
5. فاصله‌ها و تشابه تاپل‌ها  
6. Apriori / Closed / Maximal  
7. Clustering  
8. **حل کامل نمونه سوالات استاد**  
9. **ایندکس صفحه‌بندی برای پیدا کردن سریع مطالب**

## نکته امتحان جزوه‌باز

ابتدا بخش «راهنمای صفحه‌بندی» آخر PDF را باز کن، موضوع را پیدا کن، بعد تعریف + فرمول + مثال همان بخش را بنویس.
